# A049 | Zdjęcie bez kontekstu

## Status
Gotowe do użycia po wydruku / bez wydruku. Zamiast prawdziwego zdjęcia użyj tekstowego opisu kadru; bez wydruku nauczyciel rysuje prosty szkic na tablicy albo odczytuje opis.

## Cel dla uczniów
Uczniowie ćwiczą ostrożność w wyciąganiu wniosków z obrazu, oddzielają obserwacje od interpretacji i wskazują, jakiego kontekstu brakuje do uczciwego opisu sytuacji.

## Materiały
- Opis wąskiego kadru.
- Cztery opisy interpretacyjne.
- Opis szerszego kadru jako zwrot akcji.
- Tabela: obserwacja / interpretacja / brakujące dane.

## Instrukcja dla uczniów (do odczytania)
Zobaczycie opis jednego kadru, tak jakby był zdjęciem w internecie. Nie znacie autora, daty ani miejsca. Macie wybrać najbardziej prawdopodobny opis, ale najpierw musicie wypisać, co naprawdę widać, a co jest tylko domysłem. Po chwili dostaniecie szerszy kadr i sprawdzicie, jak zmienia się interpretacja.

## Karta pracy / materiały uczniowskie
### Wąski kadr
Na zdjęciu widać przewrócone krzesło, rozsypane kartki na podłodze i otwarte drzwi do sali. Przy biurku stoi jedna osoba w bluzie z kapturem, zwrócona bokiem do aparatu. Na tablicy widać fragment napisu: "nie działa". Nie widać reszty sali, zegara ani twarzy osób.

### Cztery możliwe opisy
Opis A:
"Uczeń zniszczył salę po kłótni i uciekł z lekcji."

Opis B:
"W sali trwało ćwiczenie z ewakuacji stanowiska pracy, a krzesło przewrócono celowo jako element symulacji."

Opis C:
"Ktoś robił porządek po zajęciach plastycznych, a kartki spadły podczas przenoszenia pudełka."

Opis D:
"W sali doszło do awarii sprzętu, więc osoba przy biurku sprawdza komputer, a napis na tablicy dotyczy projektora."

### Zadanie 1: Co naprawdę widać?
Wypiszcie minimum 6 obserwacji bez interpretacji.

1. ___
2. ___
3. ___
4. ___
5. ___
6. ___

### Zadanie 2: Co jest domysłem?
Przy każdym opisie wpiszcie:

- co pasuje do kadru,
- czego nie widać,
- jaki dodatkowy dowód byłby potrzebny.

|---|---|---|---|
| A |  |  |  |
| B |  |  |  |
| C |  |  |  |
| D |  |  |  |

### Werdykt przed szerszym kadrem
Najbardziej prawdopodobny opis: ___, ponieważ ___.

Najbardziej ryzykowny opis do opublikowania bez sprawdzenia: ___, ponieważ ___.

### Werdykt po szerszym kadrze
Po zwrocie akcji zmieniamy / nie zmieniamy decyzji, ponieważ ___.

## Przebieg 45 minut
1. 0-4 min: Nauczyciel odczytuje instrukcję i wąski kadr.
2. 4-9 min: Uczniowie indywidualnie zapisują obserwacje bez interpretacji.
3. 9-18 min: Zespoły analizują cztery opisy.
4. 18-23 min: Zespoły wybierają najbardziej prawdopodobny i najbardziej ryzykowny opis.
5. 23 min: Nauczyciel podaje zwrot akcji, czyli szerszy kadr.
6. 23-31 min: Zespoły poprawiają werdykt i dopisują brakujące dane.
7. 31-40 min: Omówienie: które słowa były zbyt mocne jak na jeden kadr.
8. 40-45 min: Każdy zespół tworzy neutralny podpis pod zdjęciem.

## Zwrot akcji
Szerszy kadr:

"Na szerszym zdjęciu widać jeszcze trzy osoby trzymające pudełka z papierami, kartkę na drzwiach 'Próba organizacji stanowiska - ćwiczenie', nauczyciela stojącego przy oknie oraz projektor z komunikatem błędu. Przewrócone krzesło leży obok taśmy wyznaczającej trasę przejścia. Napis na tablicy brzmi: 'Projektor nie działa - zgłosić po ćwiczeniu'."

## Punktacja / kryterium sukcesu
Maksymalnie 20 punktów:

- 4 pkt: minimum 6 obserwacji bez oceniania intencji.
- 4 pkt: analiza czterech opisów wskazuje, co pasuje i czego nie widać.
- 3 pkt: zespół rozpoznaje najbardziej ryzykowny opis do publikacji.
- 3 pkt: werdykt po szerszym kadrze uwzględnia nowe informacje.
- 3 pkt: neutralny podpis nie oskarża i nie dopowiada faktów.
- 3 pkt: wypowiedź zespołu używa ostrożnych sformułowań: "może", "brakuje", "nie wiadomo", "widać".

Kryterium sukcesu: zespół umie zatrzymać się przed mocnym wnioskiem, jeśli obraz nie pokazuje wystarczającego kontekstu.

## Klucz lub przykład dobrego rozwiązania
Przykładowe obserwacje:

- Widać przewrócone krzesło.
- Widać rozsypane kartki.
- Drzwi są otwarte.
- Przy biurku stoi osoba w bluzie.
- Na tablicy widać fragment napisu "nie działa".
- Nie widać twarzy osób.
- Nie widać, kto przewrócił krzesło.
- Nie widać, kiedy zrobiono zdjęcie.

Przed szerszym kadrem najbardziej ostrożny wybór to D albo C, bo nie oskarżają bez dowodu. Opis A jest najbardziej ryzykowny, bo przypisuje winę, konflikt i ucieczkę, których nie widać.

Po szerszym kadrze najlepszy opis:
"W sali trwało ćwiczenie organizacji stanowiska, równocześnie zgłoszono problem z projektorem. Przewrócone krzesło i kartki są elementem sytuacji widocznej w szerszym kadrze, ale samo wąskie zdjęcie nie wystarczało do oceny."

Przykład neutralnego podpisu:
"W sali widać przewrócone krzesło, kartki i osoby porządkujące stanowisko podczas ćwiczenia. Kontekst wskazuje na symulację, nie na zniszczenie sali."

## Uwagi dla nauczyciela
- To zadanie działa bez obrazu, bo najważniejszy jest mechanizm kadrowania i podpisu.
- Pilnuj, aby uczniowie nie tworzyli historii o realnych osobach.
- Przy klasie szybko pracującej poproś o napisanie dwóch podpisów: manipulującego i uczciwego.
- Przy omawianiu podkreśl różnicę między "widać przewrócone krzesło" a "ktoś zniszczył salę".
