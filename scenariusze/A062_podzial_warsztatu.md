# A062 | Podział warsztatu

## Status
Gotowe do użycia po wydruku / bez wydruku. FALA 1.

## Cel dla uczniów
Uczniowie negocjują grafik korzystania ze wspólnego warsztatu i sprzętu, uwzględniając ograniczenia czasu, priorytety zleceń i minimalne potrzeby kilku ekip.

## Materiały
- Karty ról dla ekip albo dane przepisane na tablicę.
- Jedna karta harmonogramu na zespół.
- Długopisy.

## Instrukcja dla uczniów (do odczytania)
W fikcyjnym centrum szkoleniowym są trzy ekipy, które potrzebują tej samej przestrzeni i sprzętu. Nikt nie może dostać wszystkiego. Waszym zadaniem jest uzgodnić grafik, który da się wykonać i który każda ekipa może zaakceptować. Liczy się nie tylko wygrana własnej roli, ale podpisanie planu, który przechodzi przez całą grupę.

## Karta pracy / materiały uczniowskie
Dostępny warsztat:
- Godziny: 8:00-14:00.
- Stanowiska: `S1` i `S2`.
- Jeden wspólny zestaw narzędzi precyzyjnych `N`.
- Jedna strefa testów `T`, dostępna tylko 12:00-14:00.

Zasady:
- Jedna ekipa może używać maksymalnie jednego stanowiska naraz.
- Narzędzia `N` mogą być tylko u jednej ekipy w danej godzinie.
- Test `T` wymaga wcześniejszego minimum 2-godzinnego przygotowania na stanowisku.
- Każda ekipa musi dostać minimum 2 godziny pracy.

Karty ekip:

| Ekipa | Potrzeby | Priorytet | Minimalny wynik akceptowalny |
|---|---|---|---|
| A: montaż | 3 h na S1 lub S2, 1 h z N | zamówienie seryjne | 3 h pracy i 1 h z N |
| B: diagnostyka | 2 h na S1, 1 h z N, 1 h testu T | klient czeka na wynik | 2 h S1 i 1 h T |
| C: prototyp | 2 h na dowolnym stanowisku, 2 h testu T | pokaz następnego dnia | 2 h pracy i 1 h T |

Pusta tabela grafiku:

| Godzina | S1 | S2 | Narzędzia N | Test T |
|---|---|---|---|---|
| 8-9 |  |  |  | niedostępny |
| 9-10 |  |  |  | niedostępny |
| 10-11 |  |  |  | niedostępny |
| 11-12 |  |  |  | niedostępny |
| 12-13 |  |  |  |  |
| 13-14 |  |  |  |  |

Zadania zespołu:
1. Przydzielcie godziny dla A, B i C.
2. Sprawdźcie, czy nikt nie używa `N` albo `T` równocześnie.
3. Zaznaczcie, które potrzeby są spełnione, a które ograniczone.
4. Zapiszcie jedną ustaloną zasadę kompromisu.

## Przebieg 45 minut
| Czas | Działanie |
|---:|---|
| 0-5 min | Wprowadzenie i podział ról w zespołach. |
| 5-12 min | Ekipy czytają potrzeby i zgłaszają żądania. |
| 12 min | Zwrot akcji. |
| 12-28 min | Negocjacje i ułożenie grafiku. |
| 28-36 min | Sprawdzenie konfliktów sprzętu. |
| 36-42 min | Prezentacja 2-3 grafików. |
| 42-45 min | Podsumowanie: dobry kompromis ma jasne ograniczenia. |

## Zwrot akcji
Po 12 minutach ekipa B dostaje pilne zlecenie: test `T` musi mieć o 12:00-13:00, inaczej traci 6 punktów. Ekipa C nadal potrzebuje testu, ale może zaakceptować tylko jedną godzinę testu, jeśli dostanie 3 godziny pracy na stanowisku.

## Punktacja / kryterium sukcesu
Maksymalnie 40 punktów:

| Kryterium | Punkty |
|---|---:|
| Grafik nie ma konfliktów stanowisk, N ani T | 10 |
| Każda ekipa ma minimum akceptowalne po zwrocie akcji | 10 |
| Plan uwzględnia priorytet B o 12:00 | 5 |
| Zespół zapisuje realny kompromis, nie tylko tabelę | 5 |
| Wykorzystanie warsztatu jest efektywne, bez wielu pustych godzin | 6 |
| Zapis jest czytelny | 4 |

Kryterium sukcesu: wszystkie trzy ekipy mogą podpisać grafik, a tabela nie zawiera równoczesnego użycia tego samego zasobu.

## Klucz lub przykład dobrego rozwiązania
Przykładowy grafik po zwrocie akcji:

| Godzina | S1 | S2 | Narzędzia N | Test T |
|---|---|---|---|---|
| 8-9 | B przygotowanie | A montaż | B | niedostępny |
| 9-10 | B przygotowanie | A montaż | A | niedostępny |
| 10-11 | C prototyp | A montaż | wolne | niedostępny |
| 11-12 | C prototyp | C prototyp | wolne | niedostępny |
| 12-13 | A dokumentacja poza stanowiskiem | C prototyp | wolne | B |
| 13-14 | wolne | C poprawki | wolne | C |

Spełnienie:
- A ma 3 h pracy i 1 h z N.
- B ma 2 h S1, 1 h z N i test 12-13.
- C ma 4 h pracy na stanowisku i 1 h testu, więc akceptuje skrócony test.

Zasada kompromisu: pilny termin B ma pierwszeństwo w T, ale C dostaje dodatkową godzinę stanowiska zamiast drugiej godziny testu.

## Uwagi dla nauczyciela
- Jeśli grupa się spiera, przypomnij minimalny wynik akceptowalny. To ogranicza "walkę o wszystko".
- Przy 30 uczniach zrób kilka niezależnych negocjacji w zespołach 5-osobowych.
- Rolę obserwatora można dać piątej osobie: pilnuje konfliktów w grafiku.
